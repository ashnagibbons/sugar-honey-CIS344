# Sugar & Honey Website - CIS344 Homework Assignment 3
Website hosted locally using XAMPP using PHP files for home page, header and footer. Theme is a bakery called Sugar &amp; Honey

To host:
1. Install XAMPP on your local machine. 
2. Copy index.php, header.php, footer.php, and style.css to a new folder.
3. Place that folder into the htdocs folder in your XAMPP file.
4. In your web browser, go to localhost/[folder-name]/
